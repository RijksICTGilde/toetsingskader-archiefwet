# Product Decision Records (PDR's)

Deze map bevat de besluiten over het Toetsingskader Archiefwet als site: wat is besloten, wanneer, waarom en met welke status.

## Wat is een PDR?

Een Product Decision Record beschrijft één besluit over het product, met de achtergrond, de overwegingen, de impact en de alternatieven. Elke PDR heeft een nummer, een datum en een status.

De status is een van: Voorgesteld, Geaccepteerd, Afgewezen, Vervangen of Verouderd. Een PDR die niet meer geldt, blijft staan en verwijst naar de opvolger.
